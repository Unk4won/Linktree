# Personal Linktree 🚀

Un clon de Linktree personalizado, rápido y totalmente responsivo. Construido desde cero para agrupar enlaces profesionales y redes sociales en un solo lugar con un diseño moderno.

## 🔗 Live Demo

[¡Mira el proyecto en vivo aquí!](https://Unk4won.github.io/tu-repositorio/)

## 🎨 Características UI/UX

- **Tema Oscuro & Neón:** Diseño moderno con contrastes altos para reducir la fatiga visual.
- **Tipografía Fluida:** Implementación de clamp() en CSS para que los textos y el avatar se adapten a cualquier tamaño de pantalla.
- **Animaciones Suaves:** Efectos hover interactivos con resplandores y transiciones fluidas.

## 🛠️ Tecnologías y Arquitectura

- **HTML5 Semántico:** Uso correcto de etiquetas y atributos ARIA para accesibilidad.
- **CSS3 Moderno:**
  - Metodología BEM (Block Element Modifier) para un código escalable.
  - CSS Custom Properties (Variables) para colores y espaciados.
  - Flexbox para alineación.
  - Diseño Mobile-First.

## ⚙️ Uso Local

Este es un proyecto estático, no requiere instalación de dependencias.

1. Clona el repositorio: `git clone https://github.com/Unk4won/tu-repositorio.git`
2. Abre el archivo `index.html` en tu navegador web.
